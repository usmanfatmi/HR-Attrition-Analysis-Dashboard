# HR Employee Attrition Analysis Dashboard

## Overview

This project analyzes employee attrition using Excel dashboards, SQL queries, and HR employee data. The objective is to identify the key factors influencing employee turnover and provide actionable business insights through interactive visualizations.

The dashboard allows HR professionals and business analysts to monitor employee attrition across different departments, job roles, demographics, and work-related factors.

---

## Project Objectives

- Analyze employee attrition trends
- Identify departments with the highest attrition
- Compare attrition across job roles
- Study the impact of overtime on employee turnover
- Analyze attrition by age group, gender, education, marital status, business travel, and experience
- Build an interactive Excel dashboard using Pivot Tables and Slicers
- Practice SQL queries for HR analytics

## Key Insights

- Overall employee attrition rate is **16.12%**.
- Research & Development department has the highest employee attrition.
- Laboratory Technicians and Sales Executives experience the highest attrition among job roles.
- Employees working overtime have a higher attrition rate.
- Younger employees leave the organization more frequently than senior employees.
- Employees who travel frequently tend to have higher attrition.

## How to Use

1. Download the repository.
2. Open `HR PROJECT.xlsx`.
3. Navigate to the Dashboard sheet.
4. Use the slicers to filter the data interactively.
5. Run the SQL queries from `HR ANALYTICS SQL QUERIES.sql` to reproduce the analysis.
